## 摘要
卡兹克开源自己每天在用的 4 个 Skill + 1 个 Prompt：storage-analyzer（磁盘清理）、hv-analysis（横纵分析）、khazix-writer（用他的口吻写公众号长文）、AIHOT 相关；核心是「把个人方法论封装成 AI 能遵守的规则」。

## 关键内容（转述 + 来源标注）
1. khazix-writer 的核心：禁忌词（拒绝"赋能/抓手/闭环"等 AI 腔）+ 判断顺序 + 自检体系 + 风格示例库；规则必须可检查。2. Skill 的「适合/不适合」清单写得非常清楚，避免乱用。3. 安装即用：把 GitHub 链接丢给 Agent 即可装。

## 可做知识点的点
- Skill=把个人方法论封装成规则；写红线比写目标重要（候选9·已入落地包）
- 禁忌词+判断顺序+示例库=写作 Skill 三件套（模块四）
