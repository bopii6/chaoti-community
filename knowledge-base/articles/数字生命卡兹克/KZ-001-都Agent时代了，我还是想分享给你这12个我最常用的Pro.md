## 摘要
卡兹克把过去几年最常用的 12 个 Prompt 整理成合集，覆盖「问清问题 / 学习 / 解决问题 / 决策 / 认识自己」五大场景；GitHub 上有把同一份内容工程化分发到 WorkBuddy / Claude Code / Cursor / Trae / CodeBuddy / 通用 md 的多端版本。

## 关键内容（转述 + 来源标注）
1. 12 个 Prompt：①苏格拉底式提问（追问理清本质问题）②双层解释法（小白版+专业版讲透概念）③反向拆解（拆优秀范例学它为什么有效）④横纵分析法（纵向脉络+横向对比研究陌生领域）⑤事实核查（联网查真伪、揪逻辑漏洞）⑥专家会诊（3 个互补视角互相质疑）⑦第一性原理（回归本质推倒重来）⑧跨领域借解（借其他领域机制解当下难题）⑨双向钢人论证（两难时最强双向论证）⑩用最小实验替代空想（低成本可逆实验验证假设）⑪挖掘隐藏天赋（多轮对话挖底层天赋）⑫人生设计术（斯坦福式，产出三个五年版本）。2. 工程化要点：一份源头（generate.py 内嵌 PROMPTS 列表）→ 自动生成 6 种分发格式，单一来源、多端同步；「零绝对路径依赖」，clone 即可用。

## 可做知识点的点
- 反问/复述/列假设是派活的起点（候选1·已入落地包）
- 专家会诊、第一性原理、最小实验可做成模块一独立的「决策工具箱」
- 12 个 Prompt 的「一个源头多端分发」是模块四工程化样板
