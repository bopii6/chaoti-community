## 摘要
賽博禅心用扣子3.0 远程遥控家里的 Claude Code，摆脱 IP/设备限制，双 Agent 接力干活；演示了「Agent 可以被远程调度」的工作方式。

## 关键内容（转述 + 来源标注）
1. 手机遥控 Claude Code：Agent 不一定跑在你面前，可远程调度。2. 双 Agent 接力：一个 Agent 产出，另一个 Agent 接手，分工接力。3. 对普通人的含义：算力/环境可托管，人只做指挥。
