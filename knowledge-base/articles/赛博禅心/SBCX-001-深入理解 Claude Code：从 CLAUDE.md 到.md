## 摘要
賽博禅心系统拆解 Claude Code 的四层机制：CLAUDE.md（项目规则）/ Hooks（事件钩子）/ Skills（能力包）/ Subagents（子智能体），每层各管一摊，是理解 Agent 工程化的入门地图。

## 关键内容（转述 + 来源标注）
1. CLAUDE.md=项目级规则（人写，常驻）。2. Hooks=事件触发脚本（如提交前检查）。3. Skills=按需加载的能力包。4. Subagents=专门任务的子智能体。5. 分层理解：规则（静态）vs 钩子（事件）vs 能力（按需）vs 分工（并行）。
