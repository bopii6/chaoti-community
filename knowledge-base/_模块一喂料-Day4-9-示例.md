# 模块一喂料：从聊天到 Agent（Day 4-9）
> 说明：按课程表写法（主标题/小副标题/当天产出），把知识库素材喂进每节课。素材全部可溯源：卡兹克60篇全文 + 李继刚/歸藏/傅盛精读 + 榜单抓取。
> 每课结构：这节课教什么 → 知识库素材 → 当天产出怎么做 → 直播演示 → 常见误区 → 学员验收

## Day 4｜聊天工具和 Agent 智能体的本质区别

- **小副标题**：同一件事做两遍：一次问答，一次连续交付
- **这节课教什么**：Chat 是"一问一答给建议"，Agent 是"接活→拆解→干活→交文件"。先让学员亲眼看到差别，再反推概念。
- **知识库素材**：
  1. 卡兹克60篇《都Agent时代了，12个最常用的Prompt》——Prompt 从"一句话"到"一套协作"的演进（已存全文）；
  2. 卡兹克60篇《Agent 在真实场景成功率依然很低》——Agent 不等于万能，先管理预期；
  3. 傅盛·养龙虾系列（已精读）——Agent=连续交付，Chat=一问一答；
  4. 歸藏《从 Prompt 到 Harness，上下文就是一切》——Agent 背后是"工作台"，上下文决定成败；
  5. 榜单素材：卡兹克《从0到1速通WorkBuddy》《体验完微信Agent》——国内最典型的 Agent 入口。
- **当天产出怎么做（Chat/Agent 选择表）**：
  1. 列出自己本周 5 个真实任务；2. 每个任务问两遍：需要"建议"还是"成品"；3. 需要成品的，再问"步骤稳不稳、结果能不能检查"；4. 填进两列表格（用 Chat / 用 Agent）。
- **直播演示（20 分钟）**：同一个任务"帮我写个周报"做两遍——A 在 Chat 里问（得到一段话）；B 用 Agent 派活（自动查数据→写→排版→交付 .md 文件）。现场对比"一段话 vs 一个文件"。
- **常见误区**：把 Agent 当高级搜索框（还是只问不派活）；以为 Agent 一定比 Chat 强（小任务用 Agent 反而慢）。
- **学员验收**：能说出"我这周哪 1 件事该用 Agent、为什么"，并交一张选择表。

## Day 5｜提示词就是老板的能力：把活交代漂亮

- **小副标题**：把"帮我弄一下"写成 AI 真能执行的派活单——先让 AI 复述、列假设、确认再干
- **这节课教什么**：派活单四要素（目标/材料/边界/验收）+ 反问三步（复述→列假设→确认），把"交代活"变成可复制的能力。
- **知识库素材**：
  1. 卡兹克《一个极度实用的深度思考Prompt》（双向钢人，已存全文）——"先让 AI 反问"的完整方法；
  2. 卡兹克 12 个 Prompt 合集——苏格拉底提问/专家会诊等可直接粘贴的原文；
  3. 李继刚《Prompt 的道和术》（已精读）——提示词之道是"清晰表达"；garbage in garbage out（片汤话只得 30-40 分）；
  4. 李继刚——分配角色=超级压缩包、给示例（few-shots）、思维链"一步步思考"（三个当场能用的技巧）。
- **当天产出怎么做（一张派活单）**：模板=目标（要什么成品）／材料（给 AI 什么输入）／边界（不许做什么、用什么风格）／验收（怎么算好）。先用"帮我弄一下"写一版，再用反问三步让 AI 补齐，改出第二版。
- **直播演示（25 分钟）**：现场演示反差——A：片汤话"帮我写个产品介绍"（输出 30 分）；B：派活单+反问三步（输出 90 分，直接可用）。让学员投票两版差距。
- **常见误区**：把"多问几步"当麻烦（省的是返工 10 步）；只抄 Prompt 模板不懂为什么（换个任务就不会了）。
- **学员验收**：AI 执行前能准确复述任务且说出 2 条以上你没明说的假设；交付一张能直接用的派活单。

## Day 6｜Agent 为什么总是跑偏？

- **小副标题**：不是 AI 笨：找到目标、材料、边界和验收哪里缺了
- **这节课教什么**：跑偏是常态不是异常；用"纠偏四查"（目标/材料/边界/验收）定位缺哪块，改完重跑，而不是换工具。
- **知识库素材**：
  1. 卡兹克60篇《Agent 在真实工作场景的成功率依然很低》——跑偏是真实常态，先认命再纠偏；
  2. 卡兹克·双向钢人——"逼 AI 给明确判断和行动，别让它不粘锅"；
  3. 傅盛·养龙虾（已精读）——先小步试错：让 Agent 跑小测试再上真任务；能放手的放手、要验收的抓牢；
  4. 李继刚——效果不好"回退到脑海里的东西"，别在外面乱试词；
  5. 歸藏——"AI 不知道的三件事：真实环境、过时知识、你的偏好"。
- **当天产出怎么做（跑偏纠偏记录）**：模板=任务目标／我给的材料／它跑偏成什么样／四查缺了哪块／我补了什么／重跑结果。
- **直播演示（20 分钟）**：故意给 Agent 一个模糊任务让它跑偏，现场用"纠偏四查"逐项检查，找到缺的那块，修正后重跑一遍。展示"跑偏→定位→修好"的全过程。
- **常见误区**：一跑偏就换工具/换模型（问题在派活不在工具）；让 Agent 一次性干完才检查（要设检查点）。
- **学员验收**：交一份纠偏记录，能说出"我的任务卡在四查的哪一查"。

## Day 7｜Agent 智能体最佳搭配

- **小副标题**：不比较十个工具，只为你当前任务选一个主工具
- **这节课教什么**：按任务选工具（一主一备），而不是收藏十个工具吃灰；给出主流 Agent 工具的分工地图。
- **知识库素材**：
  1. 卡兹克60篇——WorkBuddy（国内最适合的 Agent 产品）、微信 Agent、Claude Code/Codex 的实测文章（已存全文）；
  2. 榜单抓取·卡尔的AI沃茨——实测腾讯 Marvis（手机指挥电脑）、OpenClaw 桌面版、Claude/Codex 跨会话；
  3. 榜单抓取·蒼何——"豆包开始做普通人的 Codex""能跨端使用的 Agent 才是好 Agent"；
  4. 傅盛——"AI 是员工不是搜索框"（工具按"能不能交付成品"选）。
- **当天产出怎么做（一主一备表）**：列 3 个本周真实任务 → 每个任务选 1 个主工具（写文案/办公交付用 WorkBuddy 类；写代码/做自动化用 Codex/Claude Code 类）→ 填理由 → 再选 1 个备用。
- **直播演示（15 分钟）**：三个常见任务（写文案/整理资料/做 PPT）各演示 1 个主工具，讲清"什么任务配什么工具"，不横向拉踩。
- **常见误区**：收藏十几个工具全装（上下文/精力都被拖垮）；跟着热点换工具（没把一个用熟）。
- **学员验收**：交"一主一备"表，能说清每个任务为什么选它。

## Day 8｜用 Agent 要花多少钱？

- **小副标题**：月费、额度、失败重跑和时间成本，算清一次小任务
- **这节课教什么**：把"AI 不要钱"的错觉纠正成"算清一次任务的真实成本"，并学会用停止条件防烧钱。
- **知识库素材**：
  1. 卡尔的AI沃茨（榜单）——《赶在DeepSeek涨价前，猛烧1千测了6个省token的Skills》《烧了一万块API后找到AI工作流》——真实烧钱经验；
  2. 卡兹克60篇《浪费20亿Token之后，我开源了一个帮自己定义目标的Skill》——Token 成本意识；
  3. 歸藏——《单位 Token 能解决多少问题，比 Token 总量更重要》；
  4. 内部研究·卡兹克专题——定时任务前必须有测试输入/停止条件/失败恢复（成本失控的防线）。
- **当天产出怎么做（成本估算表）**：选一个真实任务，填：工具月费/单次额度消耗/失败重跑次数/你的时间成本 → 算单次总成本 → 写下"停止条件"（花到多少就停/遇到什么就停）。
- **直播演示（15 分钟）**：现场算一个任务（如"让 Agent 整理 100 条聊天记录"）的完整成本：额度+失败重跑+时间，展示"看着免费，算完 5 块钱"。再演示设停止条件。
- **常见误区**：只盯月费不盯重跑成本（失败重跑才是大头）；不给定时任务设停止条件（半夜跑飞烧钱）。
- **学员验收**：交一张成本估算表 + 停止条件，能说出"我这个任务最烧钱的是哪一项"。

## Day 9｜GitHub：你的宝藏智能库

- **小副标题**：只在需要安装工具时，学会看 README、判断风险、保存项目
- **这节课教什么**：GitHub 不是程序员专属——会"看、判、装、存"四步就能用好开源工具；安全判断是重点。
- **知识库素材**：
  1. 卡兹克60篇——khazix-skills 开源、"一句话安装 Skill 破除 GitHub 门槛"；
  2. 宝玉 baoyu-skills（已精读）——3 个月 1.6 万星，npx skills add 一句话安装（内容生产全家桶）；
  3. 卡兹克《85 个 skill 只留 30 个》——工具要筛选、分层、定期淘汰；
  4. 榜单抓取·歸藏——开源 PPT Skill/配图 Skill 等真实项目可当场演示。
- **当天产出怎么做（安全判断记录）**：打开 1 个真实项目 → 看 README（干什么/怎么装）→ 看星数/更新时间/作者 → 判断风险（要什么权限）→ 安装跑通 → 记录"项目名/地址/判断依据/用途"。
- **直播演示（20 分钟）**：现场打开 baoyu-skills（或歸藏 PPT Skill），教看 README、星数、授权、风险，一键安装，当场跑通一个功能。
- **常见误区**：看到 GitHub 就害怕（只需会看 README）；不看权限就装（乱装 Skill 有风险）；装一堆不用（要筛选淘汰）。
- **学员验收**：交"找到一个真实可用工具 + 安全判断依据"，能复述"我为什么敢用它"。

## 模块一结束状态（对接课程表）

> 学员能：分清 Chat/Agent、写一张派活单、跑偏会纠偏、按任务选工具、算清成本、安全用 GitHub。
> 对应 30 天带走第 1、2 样：一张自己会写的派活单 + 一个选定用熟的主工具。
