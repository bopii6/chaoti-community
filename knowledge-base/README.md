# 公众号内容收录库（knowledge-base）

> 用途：把市面一线 AI 公众号博主的文章**收录、沉淀、持续复用**，供「小王AI课」课程开发直接取用，避免每次重新爬取。
> 建库日期：2026-08-23 ｜ 维护方式：增量收录（详见下）

## 一、目录结构

```
knowledge-base/
├── README.md              # 本文件：收录规范与使用说明
├── _index.md              # 总台账（全量文章索引，Markdown 表格，可筛选）
├── articles/              # 收录条目（每篇一个 .md）
│   ├── 数字生命卡兹克/     # 按公众号分目录
│   ├── 宝玉/
│   └── ...
└── ../knowledge-points-100-v1.md   # 知识点池（产出，放库外，本库引用）
```

## 三、收录条目的字段规范

每篇 `articles/` 下的文件用统一格式：

```markdown
---
id: KZ-001                # 唯一编号（公众号拼音缩写-序号）
公众号: 数字生命卡兹克
作者: 卡兹克
标题: 都Agent时代了，我还是想分享给你这12个我最常用的Prompt
发布日期: 2026-08-21
原文链接: https://mp.weixin.qq.com/s/...
收录来源: 搜狗搜索 / 转载源 / 用户提供
状态: 已精读 | 仅索引 | 待精读
课程模块: 模块四
关联知识点: K-xx, K-xx
---
## 摘要
## 关键内容（转述 + 标注来源，不整段照抄）
## 可做知识点的点
```

**唯一键（去重依据）**：`公众号 + 标题 + 发布日期`，三者相同视为同一篇，不重复收录。

**状态定义**：
- `仅索引`：只有标题/日期/链接，未精读（占多数，先建索引）
- `已精读`：已读全文，含摘要与知识点
- `已入课`：知识点已确认进课程（对应落地包）

## 四、增量收录流程（以后不用重新爬）

1. **来源**：
   - 我搜索/爬取到的新文章（搜狗、全网、博主其他平台）
   - **你提供的**：微信里打开公众号 → 右上角人形图标 → 公众号主页/历史消息，截图或分享链接给我；或直接丢任意文章链接
   - 博主自己的 GitHub / 独立站 / 转载源（标注「来源：公众号XX」的，可确认为原文）
2. **入库**：按上面格式写入 `articles/`，同时更新 `_index.md` 台账（去重后追加）。
3. **提炼**：每周/每批对「已精读」条目提炼知识点，追加进 `knowledge-points-100-v1.md`。
4. **校验**：每批收录后给一份「本次新增 N 条」的小结，你确认。

## 五、版权与使用

- 收录目的：课程研发内部参考。
- 内容一律「转述 + 标注来源」，不整段照抄进课件；商用引用需按原作者授权要求处理。
- 原文链接尽量保留（搜狗跳转链接有时效，若失效可重新搜索定位）。
