# 知识库模块 4 课（待确认）

> 本模块的统一主线：把知识库从“收藏夹”变成 Agent 能找到、读懂、写回的个人工作底座。保留作者的本地优先、目录索引、及时落盘和安全边界，同时补上收件箱、来源/时效、复核、备份和检索验收。

## 学习弧线

```text
先选真实任务 → 选本地文件底座 → 建 Agent 能导航的结构 → 持续筛选、落盘、复核
```
| 编号 | 标题 | 小副标题 | 当天产出 |
|---|---|---|---|
| K1 | 知识库进阶：为什么要学习知识库？ | 从收藏夹到 Agent 的工作底座：先定义要解决的任务 | 一页「我的知识库规划」+ 5 个检索测试问题 |
| K2 | 知识库进阶：为什么我们要选择 Obsidian？ | Obsidian 只是编辑器，本地 Markdown 才是底座 | 一个本地 Vault + 安全的最小目录 + 备份方案 |
| 3.3 | 知识库进阶：让外部素材自动流进来 | 从收件箱到正式知识：筛选、落盘、复核、归档 | 一条带来源、判断、状态和复核时间的素材记录 |
| 3.4 | 知识库进阶：让 Agent 读你的知识库 | 目录是地图，README 是路牌，Agent 先读规则再找文件 | 一个 Agent 能读的最小知识库（内容层 + 导航层 + 连通测试） |
