# 2.11｜知识库进阶：为什么我们要选择 Obsidian？
> 知识库模块（七十二变之一变：让 Agent 懂你）｜ 状态：待确认 ｜ 2026-08-24

## 课眼
让学员理解选择 Obsidian 的理由：本地文件、隐私边界、Markdown、普通文件夹、可迁移和适合 Agent 调用。选工具不是追功能，而是选一个能长期承载自己资料的底座。

- **主标题**：知识库进阶：为什么我们要选择 Obsidian？
- **小副标题**：本地文件、Markdown、可迁移：让知识库真正适合 Agent 调用
- **当天产出**：装好 Obsidian，建起第一个库

## 学员痛点
「知识库工具那么多，选哪个？」——担心资料被平台锁定、隐私不清楚，也担心 Agent 以后读不了自己的资料。

## 核心内容
1. 选择 Obsidian 的第一理由：本地文件，资料归自己所有，隐私边界更清楚；
2. 第二理由：Markdown 和普通文件夹天然适合 Agent 读取、检索、批量处理和迁移；
3. 第三理由：链接、标签和元数据可以给机器提供额外的上下文结构；
4. 第四理由：离线优先、可迁移、可渐进扩展，不被一个平台或 Agent 锁住；
5. 边界：团队协作、权限审批、数据库和看板场景，不一定适合用 Obsidian 代替所有工具。

## 直播演示
现场建立一个本地 Vault，建「原始材料 / 整理笔记 / 最终产出」三层文件夹，写一篇带来源和日期的 Markdown 笔记，让 Agent 找到并使用它，再用其他编辑器打开同一文件。

## 学员练习
安装 Obsidian，建一个本地 Vault 和三层文件夹，写一篇带来源、日期、用途和更新状态的 Markdown 笔记，让 Agent 完成一次读取任务。

## 验收标准
能说出 Obsidian 的本地归属、隐私、Markdown、可迁移和 Agent 友好等优势；建好一个最小 Vault；能说明备份、同步、插件和团队协作的边界。

## 常见误区
把本地文件误认为绝对安全；一上来装一堆插件；把 Obsidian 当网盘存视频和所有大附件；只看关系图谱不整理正文；没有备份和同步方案；误以为 Markdown 自动等于结构化。

## 配套模板
Obsidian 建库清单：本地 Vault / 三层文件夹 / Markdown 模板 / 标题来源日期 / Agent 读取测试 / 备份方案 / 同步边界 / 插件需求。
