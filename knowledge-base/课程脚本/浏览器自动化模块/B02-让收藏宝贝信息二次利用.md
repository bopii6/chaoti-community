# 2.14｜浏览器自动化进阶：让你的收藏宝贝信息二次利用
> 浏览器自动化模块（七十二变之一变：让 Agent 上网干活）｜ 状态：待确认 ｜ 2026-08-24

## 课眼
浏览器自动化就是让 Agent 长出手：它能打开浏览器、进入 Twitter 书签或抖音/小红书收藏夹，从你已经筛选过的宝贝信息里定向找内容，再按你的问题做提炼和分析，最后保存到文档或 Obsidian 知识库。

- **主标题**：浏览器自动化进阶：让你的收藏宝贝信息二次利用
- **小副标题**：从 Twitter 书签、抖音和小红书收藏里提炼好内容，交给 Agent 分析并沉淀
- **当天产出**：一份收藏信息分析 Markdown

## 学员痛点
「我收藏了很多好内容，但收藏之后就没有然后了」——宝贝信息躺在 Twitter、抖音和小红书里，没有变成选题、方法和自己的知识资产。

## 核心内容
1. 浏览器自动化是什么：让 Agent 像人一样打开网页、点击、滚动、读取页面文字并整理结果；登录、验证码和隐私内容仍需要人工授权；
2. 为什么从收藏夹开始：收藏内容已经经过你的第一轮筛选，不要让 Agent 在海量信息里盲目搜索；
3. Twitter 用法：打开我的书签，只从收藏内容中找指定主题，再提取作者、链接、发布时间、核心观点、可借鉴之处和与业务的关系；
4. 平台迁移：抖音收藏、小红书收藏和其他内容平台都可以用同样的方法；
5. 抓取之后做分析：区分原文事实、Agent 的归纳和自己的下一步动作，结果写入 Markdown 或 Obsidian；
6. 安全边界：本节只读和整理，不点赞、不评论、不关注、不发布、不私信、不付款、不删除收藏。

## 直播演示
现场打开 Twitter 书签，指定一个主题，让 Agent 只从收藏内容中筛选 5 条相关信息，输出作者、链接、核心观点、可借鉴之处和与自媒体业务的关系，再保存到 Markdown 文件或 Obsidian Vault。

## 学员练习
选择 Twitter 书签、抖音收藏或小红书收藏中的一个，确定一个主题，让 Agent 定向整理 5 条内容，保存为 Markdown 并检查链接、来源、分析结果和文件路径。

## 验收标准
能解释浏览器自动化的含义；能让 Agent 从收藏夹而不是全网开始定向抓取；能提出主题、数量和分析标准；结果包含原始链接、来源、核心观点和可借鉴之处；能写入文档或 Obsidian，并确认实际路径；知道登录、验证码、发布和删除需要人工确认。

## 常见误区
让 Agent 在全网盲目搜索；没有先打开自己的收藏夹；只抓标题和链接不做分析；没有限定主题、数量和输出字段；把原文、Agent 归纳和自己的观点混在一起；一开始就让 Agent 点赞、评论、发布或删除；没有检查原始链接和文件实际写入路径。

## 配套模板
```text
请使用浏览器自动化完成一次收藏信息二次利用：
1. 打开浏览器，进入我的收藏页面：____。如果未登录、遇到验证码或页面打不开，请停下来告诉我，不要绕过。
2. 只从我的收藏中查找，不要扩大到全网。
3. 从收藏内容里找出与“____”有关的内容，最多整理 ____ 条。
4. 每条记录：标题/原文摘要、作者、发布时间、原始链接、为什么值得收藏、可借鉴之处、与我的业务的关系。
5. 区分原文事实、你的归纳和我的待办；不确定的信息标记为“待核对”。
6. 将结果保存为 Markdown，写入：D:\我的知识库\素材分析。
7. 不要点赞、评论、关注、发布、私信、付款或删除任何内容。
8. 完成后告诉我抓取了几条、哪些页面无法读取、文件实际路径。
```
