# B3｜浏览器自动化进阶：监控变化自动提醒
> 浏览器自动化模块（七十二变之一变：让 Agent 上网干活）｜ 状态：待确认 ｜ 2026-08-23

## 课眼
案例课：监控是浏览器自动化的「被动技能」——盯一个页面，变了就通知你：抢课、比价、盯更新，不用一直刷。

- **主标题**：浏览器自动化进阶：监控变化自动提醒
- **小副标题**：盯一个页面，变了就通知你——抢课/比价/盯更新
- **当天产出**：一个监控任务 + 一次提醒

## 学员痛点
「怕错过，一直刷新页面」——时间全耗在盯着看。

## 核心内容
1. 选监控对象：什么变了算事（价格下降/新课开放/内容更新）；\n2. 配置：Agent 定时检查页面 → 对比变化 → 变了通知你（消息/邮件）；\n3. 通知规则：只在「该通知」时通知（别每次都吵）；\n4. 停止条件：达到目标就停（买到票/抢到课）。

## 直播演示
现场让 Agent 盯一个页面（如价格/名额），手动改一下页面数据，让它检测到变化并「通知」你。

## 学员练习
选一个你怕错过的东西（价格/课程/名额），配一个监控+提醒。

## 验收标准
能配一个监控任务；变化时能收到提醒；知道怎么设停止条件。

## 常见误区
通知规则太宽（每 5 分钟吵一次）；不设停止条件（一直跑）；监控对象选错（变量不稳定）。

## 配套模板
监控任务卡：盯什么 / 什么算变化 / 多久查一次 / 通知谁 / 何时停。
