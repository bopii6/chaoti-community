# 第 01 课｜你的 AI 只会聊天，还是能干活？
> 模块一 · ① 观念翻转 ｜ 状态：✅ 已确认 ｜ 2026-08-23

## 课眼（这一课存在的意义）
让零基础学员第一次「看见」：AI 不是问一句答一句的搜索框，而是能领活、干活、交成品的「员工」。不看见这一下，后面学派活单、学纠偏全没着落。

- **主标题**：你的 AI 只会聊天，还是能干活？
- **小副标题**：现场看 AI 把一件真事干完——这就是这门课要给你的东西
- **当天产出**：一页《我的 AI 员工画像》（我有什么活想交给它 / 它替我干什么 / 怎么算干好了）
- **来源**：卡兹克60篇《WorkBuddy上线远程控制》《从0到1速通WorkBuddy》《体验完微信Agent》+ 傅盛养龙虾（已精读）

## 学员痛点
以为 AI = 对话框 = 问一句答一句；不知道 AI 能替自己干完一整件事、交个成品出来。

## 直播演示（25-30 分钟）：三个日常任务
> 主演示完整做「问 vs 派」两遍对比；副演示快速展示「派」的效果。

### 演示一（主，12 分钟）：整理桌面
- **准备**：建一个「模拟桌面」文件夹，放 20 个乱文件（截图/PDF/Word/压缩包混放，文件名乱：微信图片_xxx.jpg、新建文档(3).docx、屏幕截图 xxx.png）
- **第 1 遍「问」（4 分钟）**：对话框问「帮我把桌面整理一下」→ AI 回一段「可以按类型建文件夹、手动拖拽」的建议 → 点评：「它说得对，但它啥也没干。这就是『问』。」
- **第 2 遍「派」（8 分钟）**：对 Agent 念派活单：
  > 目标：整理这个文件夹；材料：文件夹里所有文件；要求：图片按「日期_序号」重命名并归类、文档归一个夹、压缩包归一个夹；验收：文件夹里只剩分类夹，命名规范
- Agent 自己扫文件 → 建夹 → 移动/重命名 → 完成。**前后截图一对比**，让学员「哇」。
- **震撼点**：它碰我电脑里的文件了！

### 演示二（副，5 分钟）：清理 C 盘垃圾
- **准备**：建一个「模拟垃圾目录」（放临时文件、缓存文件、几个大文件），**绝不在直播真删系统文件**
- **派活单**：目标：找出这个目录里可清理的垃圾；要求：按大小/类型列出 TOP 10，预估释放空间；验收：一份清理报告
- Agent 扫描 → 出报告。**执行清理这一步留给学员自己确认**（安全）。
- **震撼点**：AI 能「诊断」你的电脑，还能给建议。

### 演示三（副，5 分钟）：检查 / 提升网速
- **准备**：提前测好当前网速基线
- **演示**：Agent 执行诊断（ping / 测速 / 查占用带宽的进程 / 检查 DNS）→ 给出「网速慢的三个原因 + 对应操作」
- 低风险命令（如刷新 DNS）可现场演示；重启路由器/改设置这类留给学员自己确认。
- **震撼点**：AI 能帮你「检查身体」还开出药方。

### 收尾（3 分钟）
「这就是员工和搜索框的区别。现在写下：你最想交给 AI 干的一件事。」→ 收当天产出。

## 学员练习
写下本周最想交给 AI 的 3 件事，填一页《我的 AI 员工画像》。

## 交付物
一页《我的 AI 员工画像》（任务 / 输入材料 / 要什么产出 / 怎么算好）。

## 验收标准
能说出「问 AI」和「管 AI」的 3 点区别；交一页员工画像。

## 常见误区
- 以为「会用 ChatGPT = 会用 AI」
- 把 Agent 当高级搜索框
- 以为 AI 干活必须会写代码（不需要）

## 配套模板
《AI 员工画像卡》：我有什么活想交给它 / 它替我干什么 / 要什么产出 / 怎么算干好了。

## 避坑清单（重要）
1. 用模拟文件夹，别动真桌面、真系统文件；
2. 清理 C 盘绝不真删，只出报告、人确认；
3. 重命名规则提前定死（日期_序号格式）；
4. 三个演示全部提前自己跑通一遍；
5. 用国内工具（WorkBuddy 类），别要梯子；
6. 每个演示备好「翻车话术」：现场卡住就说「看，这就是后面为什么要教你派活单和纠偏」，把翻车变钩子。
