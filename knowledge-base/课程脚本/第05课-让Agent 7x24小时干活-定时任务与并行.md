# 第 06 课｜让 Agent 7×24 小时替你干活：定时任务 + 并行

## 课眼（这一课存在的意义）
第 4 课让学员看见 Agent 能七十二变；这一课让它「不用你盯、24 小时干活」。员工和工具的最大区别：工具等你用，员工自己到点开工、还能多线程并行。你睡觉，它干活。

- **主标题**：让 Agent 7×24 小时替你干活
- **小副标题**：定时任务到点自动开工 + 多任务并行同时干——你睡觉，它干活
- **当天产出**：一个已配置的定时任务 + 一次并行跑通记录
- **来源**：卡兹克60篇（远程操控/定时任务）+ 賽博禅心（Cron/扣子）+ 歸藏（Harness 定时）+ 内部研究（安全三件套）+ 小互AI（多 Agent 分工）

## 学员痛点
「AI 要我在它才干活，我不在它就不动」——以为 Agent 只是更好用的对话框，不知道它能自己到点上班、一次干好几件事。

## 核心内容
### 1. 定时任务（Cron）：让 Agent 到点自动开工
- 设定时间/频率，Agent 自动跑（如每天早 8 点生成日报、每周一整理周报、每晚归档素材）；
- **安全三件套（先埋点，模块三深挖）**：测试输入（先用假数据试跑）、停止条件（做到 X 就停/遇到 Y 停下等人）、失败恢复（出错退到哪、怎么通知人）。
### 2. 并行：一次干好几件事
- 一个任务拆成多块同时跑（如 10 个文件同时处理、5 个方向同时调研）；
- **并行不是开十个窗口乱跑**，是有分工的并行：谁干什么、结果合到哪，先分好。
- 进阶：多 Agent 各管一摊，主理人只拆活、验收。

## 直播演示（25 分钟）
1. **定时任务（12 分钟）**：配置一个「每天早上自动整理昨日笔记→生成日报」的定时任务，演示到点自动跑（或手动触发一次），展示「你睡它也在干活」。顺带讲安全三件套（测试输入/停止条件/失败恢复）。
2. **并行（10 分钟）**：一个任务拆成多块并行（如 10 份文件同时处理），现场对比「串行 vs 并行」的耗时，让学员看到并行不是玄学，是看得见的提速。

## 学员练习
给自己配一个定时任务（或把一件重复事拆成并行任务），跑通一次；记录配置过程。

## 交付物
《定时任务配置卡》：任务 / 触发时间 / 输入 / 停止条件 / 失败恢复 / 通知谁 + 一次并行跑通记录。

## 验收标准
- 能说出定时任务三件套（测试输入/停止条件/失败恢复）；
- 并行任务有明确分工（谁干什么、结果合到哪）；
- 至少一个定时任务或并行任务真实跑通。

## 常见误区
- 定时任务不设停止条件（半夜跑飞，钱没了）；
- 把「并行」理解成开十个窗口乱跑（没有分工的并行是灾难）；
- 以为 7×24 就是一直开着（是有计划的定时 + 有分工的并行）。

## 配套模板
《定时任务配置卡》：任务 / 触发时间 / 输入材料 / 停止条件 / 失败恢复 / 通知谁。
