# 3.1｜AI类目，跑通一遍：AI自媒体内容数字员工
> 工作流和自动化模块｜状态：待确认｜2026-08-24

## 课眼
把 Agent、Skill、知识库和浏览器自动化组合起来，跑通一个真正能干活的自媒体内容数字员工。

- **主标题**：AI类目，跑通一遍：AI自媒体内容数字员工
- **小副标题**：把 Agent、Skill、知识库和浏览器自动化串起来，完整跑通一次内容生产
- **当天产出**：一条“收藏素材 → 公众号初稿”的完整工作流

## 学员痛点
「Agent、Skill、知识库和浏览器自动化我都听过，但它们到底怎么组合，什么程度才算真的做成？」——学会了零件，却没有一个能交付结果的员工。

## 核心内容
1. **把数字员工说具体**：本课不做万能个人助手，而是先做一个“自媒体内容数字员工”，可以叫“小王的内容素材研究员”或“公众号内容助理”；
2. **明确岗位边界**：负责从收藏和聊天中收集素材、分析内容、沉淀知识、生成选题和公众号初稿；不负责未经确认的发布、付款、删除和对外发送；
3. **理解四样能力如何配合**：浏览器自动化负责拿素材；Skill 负责分析；Obsidian 知识库负责保存和提供长期资料；Agent 负责调度和交付；
4. **串起完整链路**：Twitter 书签/抖音收藏/小红书收藏/AI 聊天 → 浏览器自动化采集 → Skill 分析 → 写入 Obsidian → 知识库调用 → 选题与大纲 → 公众号初稿 → 人工确认；
5. **真正跑通一次**：让所有能力在同一个真实内容任务中各司其职，最后交付选题和公众号初稿。

## 直播演示
让 Agent 打开 Twitter 书签，按“AI Agent 商业化”筛选 5 条收藏内容，整理作者、链接、观点和可借鉴之处，写入 Obsidian；再读取这份素材，生成 3 个公众号选题和一份文章初稿，最后展示人工确认清单。

## 学员练习
选择 5 条收藏素材，让 Agent 完成“收藏 → 分析 → Obsidian → 选题 → 公众号大纲”链路，并记录每一步的输入、输出和卡点。

## 常见误区
把数字员工说成什么都能做；只安装工具没有跑通流程；让 Agent 从全网盲目搜索；只保存标题和链接不补业务判断；把生成初稿误认为可以自动发布。
