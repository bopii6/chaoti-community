## 二、官方安装

### 三个重要条件

1. **境外信用卡**：官方注册或订阅可能需要可用于国际账单的信用卡，是否接受某张卡由官方支付页面决定。
2. **科学上网**：准备稳定、合规的境外网络环境，登录和下载时不要频繁切换地区。
3. **境外手机号**：准备能接收验证短信的境外手机号，不使用来路不明的共享号码。

条件不齐时，不要反复切换地区或绕过风控，直接评估中转站路线。官方密码、验证码和支付信息不能交给 Agent。

### 最小流程

从 [OpenAI Codex 官方产品页](https://openai.com/codex/) 进入下载/安装入口，按页面提示登录或订阅，打开桌面端或 CLI。第一次只读取一个不含隐私的 Markdown 文件并生成摘要，先验证能否正常交付，再进入真实项目。

## 三、中转站：麒麟云

入口：[https://www.qilinapi.com/](https://www.qilinapi.com/)。官网公开页显示统一 API 基址为 `https://www.qilinapi.com/v1`，并提供登录控制台、模型广场和帮助文档入口。帮助文档当前可能要求权限，遇到无权限时以控制台和客服说明为准。

### 1. 怎么使用

注册并登录麒麟云 → 在 Dashboard 查看余额和用量 → 在模型广场查看模型 ID、分组、输入/输出价格与倍率 → 在 API Keys 创建密钥 → 用“Use Key/使用密钥”生成客户端配置。

### 2. 怎么充值，充值在哪

登录后从控制台进入“购买订阅/充值”入口（前端路由为 `/purchase`）。选择余额充值或订阅方案，支付方式、最低金额、手续费和到账时间以当前账户页面为准。提交后在“我的订单”或支付结果页确认状态，再回 Dashboard 核对余额；支付失败不要重复支付，保留订单号联系站内客服。

### 3. 在哪儿兑换兑换码

控制台的“兑换码”页面，直接地址是 `https://www.qilinapi.com/redeem`。粘贴兑换码后点击“兑换”，成功页会显示余额、并发额度或订阅有效期的变化，历史记录也在该页。不要把兑换码发到公开群。

### 4. 怎么使用密钥

进入 `https://www.qilinapi.com/keys`（API Keys）→ 创建密钥 → 填写名称 → 选择平台为 OpenAI 的模型分组 → 创建后点击“Use Key/使用密钥”。完整密钥只保存到本机安全位置；丢失就撤销并重新创建。

Windows 的核心配置如下，`YOUR_QILIN_KEY` 只是假值：

```toml
# %USERPROFILE%\\.codex\\config.toml
model_provider = "OpenAI"
model = "gpt-5.5"
model_reasoning_effort = "xhigh"

[model_providers.OpenAI]
name = "OpenAI"
base_url = "https://www.qilinapi.com/v1"
wire_api = "responses"
requires_openai_auth = false
```

在 `%USERPROFILE%\\.codex\\auth.json` 写入：

```json
{ "OPENAI_API_KEY": "YOUR_QILIN_KEY" }
```

macOS/Linux 对应路径是 `~/.codex/`。优先复制麒麟控制台“Use Key”生成的配置，模型名称要以模型广场和自己的分组权限为准。配置后重启 Codex，再做一次只读测试。

## 常见误区

- 把官方账户、中转站账户和 API Key 当成同一套凭证；
- 条件不齐时购买共享账号或绕过地区风控；
- 充值后不看订单状态，或忽略模型倍率和用量；
- 把完整 API Key 写进提示词、截图、GitHub 或网页代码；
- 配置后不重启 Codex，误以为密钥不可用；
- 一上来就跑真实项目和长任务，没有先做低风险验收。
