# 2.7｜Skill进阶：把一个大 V 蒸馏成 Skill
> Skill 模块（七十二变之一变：让 Agent 获得专长）｜ 状态：待确认 ｜ 2026-08-24

## 课眼
案例课：拆解一个你喜欢的博主（选题、开头、结构、语言和禁忌），提炼成 Skill，让 AI 学会一套可解释的方法，而不是照抄对方的句子。

- **主标题**：Skill进阶：把一个大 V 蒸馏成 Skill
- **小副标题**：分析博主的选题/风格/结构，变成你自己的写作助手
- **当天产出**：一个「XX 博主风格」写作 Skill

## 学员痛点
「看别人写得好，自己写不出来」——想把大 V 的风格变成自己的。

## 核心内容
1. **先选“方法”，再选“名气”**：选题稳定、公开样本足够、你确实想学其工作方式的博主；不要只因为粉丝多就拿来模仿。
2. **建立样本表**：至少选 8—10 篇同一类型内容，记录发布时间、选题、目标读者、标题、开头、转折、证据、结尾和互动方式。单篇爆文只能说明一次结果，不能直接证明规律。
3. **把风格拆成四层**：选题层（写什么、不写什么）；结构层（如何开场、推进和收束）；判断层（什么值得强调、什么必须有证据）；语言层（句子长短、口语浓度、比喻和禁用词）。
4. **区分可迁移规律和不可复制内容**：可以学结构、提问方式、检查顺序和叙事节奏；不要复制原文句子、独特故事、事实材料、标题模板或可识别的人设表达。
5. **写成规则+示例+自检**：不要只写“写得像某某”；改成可检查的规则，例如“开头先交代具体冲突，不用空泛时代背景”，再提供自己的样例。
6. **做同题对照测试**：给 Agent 一个博主从未写过的新题，生成“普通写法”和“加载 Skill 后的写法”，按结构、观点、证据、语言和原创性五项复盘。

## 拆解流程
1. 选定一个博主和一个垂直主题，收集 8—10 篇公开文章。
2. 先让 Agent 做文章矩阵，只记录证据，不急着下结论。
3. 找重复出现的模式：哪些特征至少在 3 篇以上出现，才进入候选规则。
4. 把候选规则改成“应该做什么 / 禁止做什么 / 如何检查”。
5. 用自己的经历、自己的案例和自己的观点重写示例库。
6. 用新主题做盲测，删除过度模仿和无法判断的规则。

## 可直接使用的提问模板
```text
我想学习这位创作者的内容方法，但不复制他的原文或个人经历。
创作者：【名称】
公开样本：【粘贴 8-10 篇文章或链接】
我的写作主题：【主题】

请分两步完成：
第一步，只做证据表：每篇文章的目标读者、选题、标题、开头、结构、证据、情绪转折、结尾和行动引导。
第二步，再归纳可迁移规则。只有在至少 3 篇样本中重复出现的特征，才列为稳定规律。

最终输出一个写作 Skill 草稿，包含：
1. 适用场景；2. 选题规则；3. 结构流程；4. 判断顺序；5. 语言偏好；
6. 禁用项；7. 2 个原创正例；8. 逐项自检表。
不得复制原文句子、独特故事、标题和事实材料；无法确认的规律标记“样本不足”。
```

## 直播演示
现场拆解一个 AI 或职场类博主的 8 篇公开文章：先做文章矩阵，再抽出 3 条稳定规律和 3 条禁忌，封装成 Skill；给一个博主从未写过的新题，做“未加载 Skill / 加载 Skill”的双版本对比。

## 学员练习
选一个你喜欢的博主，拆 3-5 篇，做成「XX 风格」Skill。

## 验收标准
能从样本中区分事实和推断；得到一个包含规则、示例和自检的写作 Skill；新主题输出能体现结构规律，但没有复制原文；能解释至少一条“为什么这样写”。

## 常见误区
只看一篇爆文；只模仿口头禅，不拆结构和判断；把“像”写成无法检查的目标；复制原文或独特经历；把博主的观点当成事实；只测熟悉题目，不测新题；为了追求像而丢掉自己的案例和观点。

## 配套模板
博主拆解表：文章链接 / 目标读者 / 选题来源 / 标题机制 / 开头动作 / 内容结构 / 证据方式 / 情绪节奏 / 结尾动作 / 语言特征 / 禁忌 / 可迁移性 / 样本数量。
