# S3｜Skills 进阶：无痛制作 Skills 技能，做出专属的技能

## 课眼

做专属 Skill 最成熟的方法，不是凭空写一套规则，而是先让 Agent（数字员工）把任务完整跑一遍，跑通之后再说一句「请把上述的技能沉淀为专属 XX 技能」。这样 Agent 会把刚才的完整过程整理成可复用的 Skill，你就能在 Codex 的 Skill 插件列表里找到它。

- **主标题**：Skills 进阶：无痛制作 Skills 技能，做出专属的技能
- **小副标题**：先跑一遍，再沉淀：把一套稳定方法变成 Agent 的专属技能
- **当天产出**：一个通过「先跑一遍、再沉淀」做出的专属 Skill

## 学员痛点

「别人的 Skill 不合我胃口」「我想让它按我的方法来」「每次都要重新教一遍」——不知道怎么做自己的专属技能，也不知道怎么把一次成功跑通的过程沉淀下来。

## 核心方法：先跑一遍，再沉淀技能

1. **先跑一遍**：在沉淀专属技能之前，你自己先用 Agent（数字员工）把任务完整跑一遍；
2. **沉淀技能**：跑完之后，再跟上一句：「请把上述的技能沉淀为一个专属的 XX 技能」；
3. **找到结果**：这样你就能在 Codex 的 Skill 插件列表里找到刚沉淀的技能。

这是非常成熟的一种使用方法，我自己制作的大部分技能都是这么做的。它的关键是：Skill 不是凭空设计出来的，而是从一次真实跑通的任务里沉淀出来的。

## 为什么用 PPT 举例：统一、可复用、变化慢

PPT 是做技能非常好的一个场景，因为它非常统一，而且复用性很强。你们公司做 PPT，不可能这个月是这个风格、下个月又变成那个风格、第三个月又变成其他风格；一般情况下，一个稳定的公司或个人，做 PPT 都得有自己的风格，一套 PPT 风格基本能一直用。

风格统一、复用性强、变化不会很快——这三个特点正好说明 PPT 是可复用、能沉淀下来的场景，非常适合做成专属技能。

## 四步做出你的专属 PPT 风格技能

1. **明确风格**：先告诉 Agent 你打算做成什么样的风格，例如正式商务、简洁大字、品牌色明显；
2. **迭代修改**：等它做完之后，你不断地去修改。一般情况下就是调整这几个要素：
   - 字号能不能大一点；
   - 能不能加上 logo；
   - 风格应该是怎么样的；
   - 色彩不要超过几个颜色。
3. **沉淀技能**：加进去不断地来回修改，经过 10 轮、20 轮修改完之后，它的 skill（技能）就沉淀下来了；
4. **最终确认**：最后再跟上一句：「请把上述我跟你聊的那些东西沉淀到我的 skill 技能里边。」

## 沉淀出来的 Skill 里有什么：三件套

沉淀后的专属 Skill，核心是把自己验证过的流程整理成三件套：

- **规则**：怎么做、不许怎么做（要可检查）；
- **自检**：怎么算对，一条条列出来；
- **示例**：一个「好」的样例，让 AI 知道目标长什么样。

先跑一遍保证方法真实跑通过，沉淀技能保证它被写成可复用规则，三件套保证它每次都能被检查和验收。

## 沉淀后怎么验证

1. 打开 Codex 的 Skill 插件列表，找到刚沉淀的专属技能；
2. 换一份新材料再跑一次，检查风格、字号、logo、色彩数量是否保持一致；
3. 不满意就继续来回修改，改完再沉淀一次，直到输出稳定。

## 现场演示（35 分钟）

现场用 PPT 场景演示完整链路：

1. 先让 Agent 按指定风格做一版 PPT；
2. 迭代 3—4 轮（字号、logo、风格、色彩）；
3. 说「请把上述技能沉淀为专属 PPT 风格技能」；
4. 在 Codex 的 Skill 插件列表中找到它；
5. 用一份新材料验证风格是否一致。

## 给 Agent 的提示词模板

```text
帮我沉淀一个专属技能：
1. 先按我的要求把任务完整跑一遍：____；
2. 跑通后，请把刚才的完整过程沉淀为『____技能』；
3. 列出沉淀后的 Skill 里包含的规则、示例和自检；
4. 告诉我如何在 Codex 的 Skill 插件列表里找到并验证它；
5. 我的风格要求（如 PPT 的字号、logo、风格方向、色彩数量）如下：____，请逐项确认。
```

## 学员练习与交付物

选一个高频且风格稳定的任务（推荐 PPT），先让 Agent 完整跑一遍，再至少迭代 5 轮（字号、logo、风格、色彩），最后说「请把上述技能沉淀为专属 XX 技能」，在 Codex 的 Skill 插件列表中找到它，并用一份新材料验证。

## 验收标准

- 能说出「先跑一遍、再沉淀技能」的核心方法；
- 能说出沉淀技能的一句话：「请把上述的技能沉淀为专属 XX 技能」；
- 能解释为什么 PPT 适合做专属技能（统一、可复用、变化慢）；
- 能按「明确风格 → 迭代修改 → 沉淀 → 最终确认」四步完成一次沉淀；
- 能在 Codex 的 Skill 插件列表中找到沉淀的技能，并用新材料验证。

## 常见误区

- 凭空设计 Skill，没有先把任务完整跑一遍；
- 任务跑完就结束，没有说「沉淀为专属 XX 技能」这句话；
- 只沉淀一次就以为完成，没有经过多轮迭代修改；
- 没有明确风格和可检查的要素（字号、logo、风格、色彩数量）；
- 沉淀后不用新材料验证，不知道技能是否真的稳定。
