# 2.8｜Skill进阶：别从零造，把别人的 Skill 改成你的
> Skill 模块（七十二变之一变：让 Agent 获得专长）｜ 状态：待确认 ｜ 2026-08-24

## 课眼
案例课：不造轮子。找到一个已经很好用、约 80% 适合你的现成 Skill，只针对那 5%—10% 无法忍受的部分提出具体要求，让 AI 在副本中修改并沉淀成新版本。

- **主标题**：Skill进阶：别从零造，把别人的 Skill 改成你的
- **小副标题**：好 Skill 直接拿来用，只改你真正忍不了的 5%—10%
- **当天产出**：一个保留原版能力、只修改个人要求的新 Skill 版本

## 学员痛点
「这个 Skill 已经很好了，但有几个细节让我无法长期使用」——不需要重写，只要让 AI 帮你改那一小部分。

## 核心内容
1. 先跑通：确认原版确实有价值，满意度约 80%；
2. 先读懂：让 AI 只读解释原版的触发方式、流程、规则、示例和边界；
3. 说具体：把“我不喜欢”改成明确的规则、示例和验收标准；
4. 做副本：让 AI 在新目录或新版本中修改，不直接覆盖原版；
5. 对照验收：确认原版有效的 80% 还在，5%—10% 的问题已经解决。

## 直播演示
现场拿一个已经很好用的写作或 PPT Skill，让 AI 先只读解释原版；提出 3 条具体修改要求；在副本中生成新版；最后用同一份材料做原版/新版对照测试。

## 学员练习
找一个你已经使用过、整体约 80% 满意的 Skill，提出 3 条最不能接受的细节，让 AI 生成副本版本，跑通并对比。

## 验收标准
能把具体不满写成可执行规则；能让 AI 先读懂原版，再在副本中修改；能证明原版能力没有被破坏；能保留修改记录和回退版本。

## 常见误区
原版没跑通就开始改；自己直接改文件；只说“自然一点”而没有具体要求；一次改太多；只测新增规则、不测原版能力；没有保留原版和修改记录。

## 配套模板
修改清单：原版来源 / 已验证的有效能力 / 我要修改的 5%—10% / 具体新规则 / 我的示例 / 对照测试 / 修改记录 / 回退版本。
